# Sports Analytics Lab

## Overview
This repository contains my personal projects in sports analytics, with a focus on data-driven decision-making, coaching strategies, and performance analysis.

## Motivation
I am a Bachelor student in Software Engineering interested in understanding how data can improve tactical and coaching decisions in sports, particularly in baseball and American football.

## Current Focus
- Baseball analytics (pitching strategies, batter tendencies, situational analysis)
- Decision-making under pressure
- Data visualization for coaching insights

## Tools & Technologies
- Python
- Pandas, NumPy
- Data visualization (Matplotlib, Seaborn, Plotly)
- Streamlit (planned)

## Roadmap

- [ ] Tactical insights for coaching decisions
- [ ] Interactive dashboard for scenario simulation
